# مسار — منصة تعليمية مجانية

## ماذا يوجد في المشروع؟
- `index.html` — الموقع الرئيسي.
- `styles.css` — التصميم والألوان.
- `app.js` — البحث، الفلاتر، صفحات المدرسين، YouTube.
- `teachers.js` — **ملف البيانات الرئيسي** للمدرسين والدروس.
- `admin.html` + `admin.js` — أداة مجانية محلية لتجهيز البيانات وتصدير `teachers.js`.

## إضافة مدرس أو فيديو بدون Database
1. افتح `admin.html` محليًا في المتصفح.
2. أضف المدرس والبيانات العامة الموثوقة عنه.
3. أضف الدروس وروابط YouTube الرسمية.
4. اضغط `تصدير teachers.js`.
5. استبدل `teachers.js` القديم بالملف الجديد.
6. ارفع ملفات الموقع المحدثة إلى الاستضافة.

> أداة الإدارة المحلية ليست قاعدة بيانات سحابية. التعديلات لا تظهر للزوار إلا بعد استبدال ملف `teachers.js` ورفع التحديث.

## YouTube
الموقع يستخدم YouTube Embed الرسمي إذا كان الرابط صالحًا، ويضع أيضًا زر "مشاهدة على YouTube". لا يتم تحميل الفيديوهات إلى المنصة.

## حقوق المحتوى
استخدم فقط المعلومات العامة الصحيحة والروابط الرسمية، واحترم حقوق أصحاب المحتوى. لا تذكر أن مدرسًا شريك أو مؤيد للمنصة إلا بموافقته.

## الاستضافة المجانية
هذا المشروع Static ويمكن استضافته على خدمات استضافة ملفات ثابتة مثل GitHub Pages أو Cloudflare Pages أو Netlify. لا يحتاج إلى Database لتشغيل النسخة الحالية.

## التوسع مستقبلًا
يمكن لاحقًا استبدال `teachers.js` بواجهة API/Database إذا أصبحت المنصة كبيرة، دون تغيير فكرة واجهة الموقع الأساسية.
